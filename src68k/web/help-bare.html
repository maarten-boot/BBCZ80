In BBC BASIC

CHAIN "menu"
the menu of demo programs
LIST, RUN
list and run the program in memory
*DIR
the files: on the SD card, then in the RAM store (the demos, *.bbc, and their text, *.bas)
*MKDIR, *CD, *RMDIR
directories on the SD card
*ERA, *REN new=old
delete and rename files
*BYE
starts BBC BASIC again (the files stay)

The machine

BBC BASIC runs straight on an emulated rosco_m68k with its firmware: no operating system. Files go to the SD card, which has a FAT16 file system (8.3 names, directories); files that are not on the card are also looked for in a RAM store, where the demo programs are. sd: and ram: in front of a name choose one. The same BASIC boots on a real rosco_m68k from its SD card and keeps its files there.

Your own programs

Load program (or dropping files on the screen) puts files on the SD card.

  • One program is loaded too: a tokenised .bbc program of BBC BASIC for Z80, CP/M, Windows or SDL with LOAD; a text listing with NEW and *EXEC (without line numbers it is numbered 10, 20, …). Then type RUN. If BASIC is not at its > prompt (the menu, a running program), the page presses Escape first.
  • Several files, or one that is not a program (not .bbc, .bas or .txt), are only copied, exactly as they are, for CHAIN, LOAD or OPENIN (programs that chain each other, data files).

Names become 8.3 and upper case: my prog.bas is MY_PROG.BAS.

Saving to your computer

Type a file name next to Download and press it (or Return): the file on the SD card is saved on your computer. A name without an extension is also tried with .BBC, as SAVE writes it:

  • a program: SAVE "myprog", then download myprog;
  • a program's output: *SPOOL out.txt, RUN, *SPOOL, then download out.txt;
  • a listing as text: *SPOOL list.txt, LIST, *SPOOL;
  • a file in a directory: SUB/PROG.BBC.

BBC Micro (Acorn) files are tokenised differently and are not understood; graphics and sound do not exist on this text terminal. The SD card is in memory: everything is gone after Reset.
