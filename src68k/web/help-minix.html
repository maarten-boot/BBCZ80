Your own programs

Load program (or dropping files on the screen) copies files into BASIC's directory (/usr/demo), through the emulated SD card and dd, so it takes a moment whatever the size. It types * commands at BASIC's > prompt: if BASIC is elsewhere (the menu, a running program), the page presses Escape first.

  • One program is loaded too: a tokenised .bbc program of BBC BASIC for Z80, CP/M, Windows or SDL with LOAD; a text listing with NEW and *EXEC (without line numbers it is numbered 10, 20, …). Then type RUN.
  • Several files, or one that is not a program (not .bbc, .bas or .txt), are copied exactly as they are, for CHAIN, LOAD or OPENIN (programs that chain each other, data files).

Saving to your computer

Type a file name next to Download and press it (or Return): the file is copied from BASIC's directory to your computer, through the SD card again. A name without an extension is also tried with .bbc and .BBC, as SAVE writes it:

  • a program: SAVE "myprog", then download myprog;
  • a program's output: *SPOOL out.txt, RUN, *SPOOL, then download out.txt;
  • a listing as text: *SPOOL list.txt, LIST, *SPOOL.

File names keep letters, digits and . _ -, at most 14 characters. BBC Micro (Acorn) files are tokenised differently and are not understood; graphics and sound do not exist on this text terminal. The disk is a RAM disk: everything is gone after Reset.
