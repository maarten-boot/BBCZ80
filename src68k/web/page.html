BBC BASIC 68000

R.T. Russell's BBC BASIC (Z80) v5, ported to 68000 assembly language, running under Minix 2.0.4 on an emulated rosco_m68k (68010) — all in this page, offline.

Keys

Esc
BBC BASIC's Escape: stops a running program
↑ ↓ ← →
edit the line being typed (start, end, left, right)
paste
types the text in (a numbered listing becomes a program)

In BBC BASIC

CHAIN "menu"
the menu of demo programs
LIST, RUN
list and run the program in memory
*DIR
the files (the demos are *.bbc, their text *.bas)
*BYE
to the Minix shell; exit there brings the demo back

Your own programs

Load program (or dropping a file on the screen) types a program into BASIC at the > prompt: a tokenised .bbc file of BBC BASIC for Z80, CP/M, Windows or SDL, or a text listing (without line numbers it is numbered 10, 20, …). Then type RUN. BBC Micro (Acorn) files are tokenised differently and are not understood; graphics and sound do not exist on this text terminal. The disk is a RAM disk: everything is gone after Reset.
